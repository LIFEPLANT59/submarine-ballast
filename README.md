# 🚢 Заправочная станция субмарины — калькулятор балласта

**Выполнил:** Шматко К.А., группа ИВТ-101
**Журнал:** №20

---

### 📝 Описание логики
Программа управляет балластом подводной лодки: по желаемой глубине
погружения рассчитывает, сколько воды нужно **докачать** или **сбросить**
в цистернах.

**Формула:**
`Целевой объём = Глубина × 60 л/м`
`Изменение = Целевой − Текущий`

*Если глубина превышает 300 м — срабатывает защита корпуса и погружение
блокируется. Если целевой объём больше вместимости цистерн (15000 л) —
миссия невозможна.*

---

### 🛠️ Сборка и запуск
```bash
g++ -std=c++17 main.cpp -o submarine
./submarine
```

### 💻 Примеры работы (тест-кейсы)

#### Сценарий 1: Погружение (докачать)
- **Вход:** объём = `2000`, глубина = `50`
- **Результат:**
```text
Введите текущий объем воды в цистернах (л): 2000
Введите необходимую глубину погружения (м): 50

Целевой объем воды для глубины 50 м: 3000 л.

[БАЛЛАСТ] ⬇️ ДОКАЧАТЬ ВОДУ: 1000 л (погружение).
```

#### Сценарий 2: Всплытие (сбросить)
- **Вход:** объём = `5000`, глубина = `40`
- **Результат:** `⬆️ СБРОСИТЬ ВОДУ: 2600 л (всплытие)`

#### Сценарий 3: Опасная глубина
- **Вход:** объём = `1000`, глубина = `500`
- **Результат:** `❌ ОПАСНО: превышен предел прочности корпуса (300 м)`

- Валидация ввода: буквы, отрицательные значения, объём больше вместимости
- Три режима работы: докачать / сбросить / уже на глубине
- Защита корпуса от запредельного погружения
- Проверка достаточности цистерн# submarine-ballast
